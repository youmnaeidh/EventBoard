# EventBoard v2 — منصة فعاليات المدينة المنورة (النسخة المطوّرة)

نسخة مطوّرة من مشروع تخرجي. النسخة الأولى كانت واجهة ثابتة (HTML/CSS/JS) تحفظ بياناتها في المتصفح. هذي النسخة موقع كامل: واجهة React، وخادم Node، وقاعدة PostgreSQL، وخدمة ذكاء اصطناعي بـPython.

**رابط العرض:** https://youmnaeidh.github.io/EventBoard/ — آخر نسخة منشورة هي v1. دُمجت v2 المختبرة في `main`، والنشر ينتظر معالجة GitHub Actions · **حسابات تجريبية:** `demo@eventboard.demo` (حاضر) و`organizer@eventboard.demo` (منظّم)، كلمة المرور `Demo#2026`.

## القصة وراء الفكرة

قضيت أيام أدور على ورشة فخار، ولقيتها بعد ما انتهت بيوم. من هنا جت فكرة "فجوات الطلب": المنصة ما تكتفي بعرض الفعاليات، تعرف أيش الناس يدورون عليه ولا يلقونه، وتنبّه المنظّم.

## وش الجديد

| | النسخة الأولى | النسخة الثانية |
|---|---|---|
| البيانات | تخزين المتصفح + CSV | PostgreSQL وهجرات وبيانات تجريبية |
| الحجز | يحفظ محليًا | حجز تجريبي محفوظ في PostgreSQL مع قفل المقاعد لمنع تجاوز السعة؛ ليس حجزًا لفعالية حقيقية |
| الدخول | تجريبي | تسجيل وجلسات (bcrypt + JWT في كوكي httpOnly للتشغيل المحلي، أو Bearer Token مؤقت داخل sessionStorage لنسخة GitHub Pages التجريبية) |
| الذكاء الاصطناعي | ما فيه | بحث ذكي بالعربي، توصيات تشرح سببها، توقّع إقبال، فجوات طلب، مساعد فعاليات |
| المنظّم | ما فيه | لوحة تحكم وتحليلات وإنشاء/تعديل/حذف فعالياته |
| الاختبارات | ما فيه | API 35 · AI 27 · الواجهة 5 · e2e أساسية 17 + GitHub Pages 5 |

الهوية الأصلية (الشعار والألوان وفيديو المدينة وصور الفعاليات) محفوظة.

## مزايا الذكاء الاصطناعي

1. **بحث بالعربي وباللهجة:** اكتب «ابغى شي للعيال الليلة ببلاش» ويفهم الوقت والسعر والجمهور، ويعرض لك "كيف فهمت طلبك".
2. **توصيات تفسّر نفسها:** كل توصية معها سببها («تشبه فعالية اهتميت فيها»، «قريبة منك 2.9 كم»).
3. **لوحة المنظّم:** توقّع عدد الحجوزات مع مدى (80%)، وأيش يرفع الإقبال أو يخفضه، وأفضل أوقات للفعالية، وفجوات الطلب (مواضيع يكثر البحث عنها وما فيها فعاليات).
4. **مساعد فعاليات:** يجيب من الفعاليات الموجودة فقط، ولا يقدر يذكر فعالية غير موجودة. يشتغل بدون مفتاح API (بقوالب جاهزة)، ولو حطيت `ANTHROPIC_API_KEY` يصيغ الجواب بـClaude.

التفاصيل والأرقام في [`docs/ai.md`](docs/ai.md).

## حالة الإصدار

خدمتا API وAI وصلتا إلى حالة Live على Render Free داخل My Workspace، وقاعدة Neon Free أُنشئت ونُفّذت الهجرات وإضافة البيانات التجريبية بنجاح. نجحت اختبارات المتصفح على الخدمات المنشورة، وأكدت المالكة تحويل مصدر Pages إلى GitHub Actions. دُمجت v2 في `main`، لكن النشر وفحص الموقع العام ينتظران زوال عطل GitHub Actions وPages المعلن. تفاصيل الفحوصات والـcommits والمتبقي في [سجل الإصدار](docs/release-status.md).

نجحت **الاختبارات الـ89 كاملة** وبناء الواجهة العادي وبناء GitHub Pages في [تشغيل CI](https://github.com/youmnaeidh/EventBoard/actions/runs/39154465651). ونجحت أيضًا **اختبارات المتصفح الخمسة على Render وNeon الفعليتين** في [تشغيل 19 أكتوبر 2026](https://github.com/youmnaeidh/EventBoard/actions/runs/39211414937)، بما يشمل الحجز والمفضلة والدخول والخروج وتوقّع AI وعرض الجوال. لقطات الشاشة الفعلية موجودة في [README الإنجليزي](README.md#screenshots). المتبقي هو اكتمال النشر بعد تعافي GitHub وفحص الرابط العام ثم نشر تحديث Portfolio.

## تشغيل المشروع

```bash
docker compose up --build        # http://localhost:4000
```

أو للتطوير: انسخ `.env.example` إلى `.env`، ثم `npm install` و`npm run dev:api` و`npm run dev:web`، وشغّل خدمة الذكاء من `services/ai` بـ`uvicorn app.main:app --port 8001`. الموقع يشتغل بدون خدمة الذكاء لكن بمزايا أقل.

## الاختبارات

```bash
npm test
(cd services/ai && python -m pytest -q)
npm run build && npm run test:e2e
```

## النشر

الواجهة تُنشر على GitHub Pages بنفس المسار `/EventBoard/`، وواجهة API وخدمة AI على Render Free، وقاعدة البيانات على Neon Free. بعد التحويل، ينشر `.github/workflows/deploy-pages.yml` تغييرات `main` بعد نجاح CI، ويفحص الخدمات قبل النشر والموقع العام بعده. فرع الإصدار الحالي لا ينشر الواجهة للعامة. راجع [`DEPLOYMENT.md`](DEPLOYMENT.md).

## حدود صريحة

- **كل بيانات النشاط تجريبية** (30 فعالية، حوالي 140 مستخدم، حوالي 8 آلاف تفاعل، و800 صف لتدريب التوقّع). الأرقام في `docs/ai.md` تثبت أن المنظومة تشتغل، وما تثبت دقة على الواقع.
- تأثيرات التوقّع (عطلة نهاية الأسبوع، المساء، السعر) افتراضات كتبتها أنا عند توليد البيانات.
- مسار Claude في المساعد والبحث الدلالي (embeddings) مكتوبين ومختبرين بمحاكاة فقط، ما جرّبتهم بمفتاح حقيقي ولا بأوزان نموذج فعلية.
- ما سويت تقييم للتوصيات (أحتاج بيانات حقيقية عشان يكون له معنى).
- خرائط OpenStreetMap تُحمَّل وقت التشغيل.
- خدمات Render Free قد تدخل وضع السكون وتحتاج وقتًا للاستيقاظ، وتخضع هي وNeon لحدود الاستخدام المجاني.
- النسخة القديمة محفوظة في فرع احتياطي وأرشيف Git كامل. الأرشفة لا تجعل تاريخ المستودع العام أو نسخه المتفرعة خاصًا.
